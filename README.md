# ContactNotes

Verteilpunkt der Android-App **ContactNotes**. Hier liegt immer nur die
aktuelle Fassung – die App lädt sie für ihr Selbst-Update von
`contactnotes.apk` und fragt vorher `contactnotes-version.txt` ab.

Dieses Repo wird bei jedem Release automatisch neu aufgesetzt; bitte
nichts von Hand ändern.
